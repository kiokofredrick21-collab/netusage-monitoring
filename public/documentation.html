ABSTRACT

This project focuses on the design, development, and implementation of the NetUsage Hub Network Usage Monitoring System to resolve critical inefficiencies in monitoring and managing network infrastructure. In many small and medium-sized organizations, network auditing and bandwidth tracking are still handled through fragmented spreadsheets or reactive manual checks, leading to unmonitored bandwidth overconsumption, unrecognized downtime, and lack of historical network audits.

The developed system provides a secure, centralized web-based portal that allows network administrators to manage hardware device inventories (routers, switches, firewalls, and access points), record bandwidth consumption metrics in real-time, generate automated threshold-based alerts when download/upload capacities are breached, and review historical usage patterns through consolidated business reports.

The system was developed utilizing PHP 8 and MySQL for the back-end logic and persistent relational storage, with HTML5, CSS3, JavaScript, and Bootstrap 5 delivering a responsive, template-driven front-end interface. The system significantly enhances network visibility, prevents unexpected bandwidth costs, and enables evidence-based capacity planning.

DEFINITION OF KEY TERMS

  • Network Monitoring System: A computerized platform used to track, audit, and evaluate the performance, status, and bandwidth consumption of networked hardware devices.
  • Relational Database: An organized collection of persistent data structured into normalized tables accessed via Structured Query Language (SQL).
  • User Authentication: A security process verifying user identity via credentials (username and hashed password) before granting administrative session privileges.
  • Dashboard: A centralized graphical user interface displaying real-time Key Performance Indicators (KPIs) such as total monitored devices, active threshold alerts, and today's total bandwidth traffic.
  • Threshold Alert: An automated system notification triggered when actual bandwidth utilization or packet loss exceeds a predefined capacity limit.

CHAPTER ONE: PROJECT PLANNING AND ANALYSIS

1.1 Statement of Problem

Despite the rapid modernization of information and communication infrastructure, many small and medium-sized organizations continue to manage their network operations using manual methods, such as physical logbooks, isolated router web interfaces, and fragmented spreadsheets. These decentralized methods create acute operational bottlenecks, including unmonitored bandwidth consumption, unexpected ISP bill overruns, unrecognized equipment downtime, and complete absence of historical audit trails (Laudon & Laudon, 2022).

In the specific operational context of NetUsage Hub in Kisii, the lack of a centralized network usage monitoring portal has caused severe inefficiencies. Device health, bandwidth quotas, and link performance are reviewed ad-hoc after network degradation or outages have already disrupted business operations. Furthermore, bandwidth allocation decisions and ISP contract renewals are executed based on guesswork rather than empirical consumption data. There is, therefore, a pressing need to design and develop a centralized, secure web-based internal management portal that automates device inventory management, logs real-time bandwidth metrics, triggers automated threshold alerts, and delivers actionable business reports.

1.2 Study Justification

The development of this project is justified by the critical need for digital transformation within local network operations centers and enterprise IT environments. Independent service hubs and small enterprises require reliable digital tools to maintain network uptime and prevent financial losses stemming from bandwidth wastage and undetected hardware outages (Rashid et al., 2025). From a management perspective, this system eliminates manual record-keeping and uncoordinated equipment audits by providing a unified portal for device status tracking, automated threshold evaluation, and data-driven bandwidth forecasting.

1.3 System Objectives

General Objective: To design, develop, and deploy a secure, web-based Network Usage Monitoring System (NetUsage Hub) for centralized network device tracking, metric logging, and threshold alert automation.

Specific Objectives:

  1. To develop a secure user authentication module utilizing session tokens and password hashing.
  2. To develop an inventory control center for registering, editing, categorizing, and deleting network devices and threshold limits.
  3. To develop an automated metric logging engine that captures download volume, upload volume, latency, and packet loss in real-time.
  4. To implement an automated threshold monitoring mechanism that triggers alerts whenever monitored devices exceed configured bandwidth quotas.
  5. To develop a search and filtering module enabling rapid retrieval of device details and logs.
  6. To design an analytical reporting and export module that calculates aggregate bandwidth consumption and exports audit records to CSV.

3.3.1 Login Authentication Logic

// Backend Authentication Function (includes/auth.php)
function attempt_login(string $username, string $password): bool {
    $stmt = db()->prepare('SELECT * FROM users WHERE username = ? LIMIT 1');
    $stmt->execute([$username]);
    $record = $stmt->fetch();
    if ($record && password_verify($password, $record['password_hash'])) {
        session_regenerate_id(true);
        $_SESSION['user'] = ['id' => $record['id'], 'username' => $record['username'], 'full_name' => $record['full_name'], 'role' => $record['role']];
        return true;
    }
    return false;
}
